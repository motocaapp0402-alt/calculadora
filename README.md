# Calculadora de Renda Fixa - ANBIMA 📊

Ferramenta em Python para simulação de investimentos em CDB, LCI/LCA e Tesouro Direto. Desenvolvida com base nas metodologias de cálculo da ANBIMA e Banco Central.

### **🎯 Objetivo do Projeto**
Unir conhecimentos do mercado financeiro, obtidos em 15 certificações ANBIMA, com habilidades de programação para criar uma ferramenta de apoio à decisão para investidores e assessores.

### **⚙️ Funcionalidades Implementadas**
- **Cálculo de CDB Pós-fixado**: Simulação com taxa DI/CETIP
- **Comparativo LCI vs CDB**: Considera isenção de IR da LCI/LCA
- **Projeção de Tesouro Selic**: Cálculo de rentabilidade líquida descontando taxas B3 e IR
- **Exportação de Relatório**: Gera `.csv` com a projeção mês a mês
